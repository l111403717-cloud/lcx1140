# 已上线项目增量开发

仅在开发或发布涉及已上线项目时读取；开发授权不自动包含生产写入或发布。

### 1.2 已上线项目增量开发（仅相关任务启用）
- **认清生产版本**：复用已授权的发布记录、版本标识或线上只读信息，确认实际生产版本与当前开发起点的差异；不能确认时明确标记，不把本地代码默认当作线上现状。独立分支或 worktree 按实际风险和项目约定使用，不因项目已上线就强制升档。
- **检查共用关系**：沿本次功能涉及的页面入口、接口、公共逻辑和数据库定点检查，列出可能受影响的旧功能及对应回归项，不扩展为全库扫描。范围和验收复用已有需求；仅已启用持久接力时补入 PLAN，不额外强制创建“实施真源文档”。
- **隔开生产环境**：开发和验证默认使用非生产环境及测试数据，确认实际连接目标；缺少隔离条件时继续可独立完成的本地工作。写入生产数据、执行生产迁移或发布须有对应授权，开发授权不自动包含这些操作，已有明确授权不重复索要。
- **核对上线版本**：仅在已授权发布时，确认待发布版本与通过验证的版本一致，具备与风险相称的回退或恢复办法；涉及数据迁移时同时考虑数据兼容与恢复。发布后检查相关线上功能，记录实际发布版本并更新相关常驻文档，未实际发布不得宣称已上线。

阶段验证通过后继续已约定范围，不增加逐阶段人工确认；只有真实决策、风险或授权缺口才提问。
